# OpenWallet

A secure, multi-chain cryptocurrency wallet with integrated AI chat capabilities.

## Features

- 🔐 **Multi-Chain Support**: Ethereum, Solana, BSC, Polygon, and more
- 💬 **AI Chat Integration**: Built-in AI assistant powered by OpenRouter
- 🛡️ **Advanced Security**: Memory protection, encryption, and secure key management
- 🎨 **Customizable Themes**: Light, dark, and custom theme options
- 📱 **Responsive Design**: Works seamlessly on desktop and mobile devices
- 🔄 **Token Discovery**: Automatic token detection across supported networks

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/openwallet.git
cd openwallet
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```
